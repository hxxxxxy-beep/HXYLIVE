Check Interval

How often tracked sources are checked for live status. Higher values reduce provider requests.

Default Recording Resolution

Resolution assigned to a model when auto-record is turned on (newly added models, or toggling auto-record off → on). Per-model values can still be edited afterward.

Default Monthly Recording Quota

Per-streamer capture budget for each quota cycle (default 100 GB). When a streamer hits the limit, captures pause without clearing the card auto-record preference. Use 0 for unlimited. Per-streamer overrides live on each Media card.

GB
Quota Cycle Start Day

Calendar day each month when the quota window resets (1–28). Default is the 13th.

Max Recording Resolution

Hard cap on the height of recorded streams — no model can exceed this even if its per-model setting is higher.

Recording Filename Format

Applies to new recordings only. New files also stamp username(source) (or timestamp_id(source)) so a Mac rescan can reopen the live room after a VPS reset.

Default Retention

Days assigned to newly tracked models (VPS library retention after Mac download). Use 0 to keep forever on the VPS.

days
Auto Convert (TS → MP4)

Automatically convert .TS recordings to .MP4 after capture

Keep TS Files

Keep original .TS files after MP4 conversion. Prefer off so the VPS only holds MP4 fragments until you download them to Mac.

Auto Record

Master switch for all captures. Turning off stops every running recording and blocks new ones, but does not clear per-streamer recording settings. Turn it back on to resume auto-record with the same streamer settings.

Staging stop (SSD)

Pause captures when SSD staging free space falls below this many GB (default 5). Recording resumes automatically only after all staging recording files are cleared.

Library stop (HDD)

Turn Auto Record off and disable the switch when HDD library free space falls below this many GB (default 100). After space recovers, the switch stays off until you turn it back on.

Resume gap buffer

How long after the last fragment before a recording project is marked finished (and new fragments start a new project). Per-streamer overrides live in the Media streamer settings. Mac downloads are manual only.

Download project concurrency

How many recording projects may download at once (1–4). Paused projects do not occupy a slot. Default 2.

Download file concurrency

Max simultaneous fragment downloads across active projects (2–12). Default 6.

Show TS Files in Recordings

Show raw .TS files in the Media library (only MP4 files are shown by default)

Segment by Duration

Split recordings into time-based parts. Off keeps one file per session.

Segment by Size

Maximum TS part size in MB. Use 0 to disable; if duration is also set, the first limit reached starts the next part.

MB
